# Блок 10. Напоминания и мотивация

Вход: **Профиль → Напоминания**. Всё выключено по умолчанию; системный запрос
разрешения вызывается только при сохранении включённых настроек. Открытие экрана
или приложения не вызывает запрос. Время по умолчанию 19:00 местного времени,
настраиваются часы, минуты, удобные дни недели и отдельные категории.

| Напоминание | Когда | Условие и действие |
| --- | --- | --- |
| Текущий день программы | Выбранные пользователем дни/время | Есть открытый уровень и текущий день; после занятия с подходами сегодня не добавляется повторное напоминание на сегодня. Открывает план, не назначает тренировку вместо отдыха |
| Сохранённая тренировка | Через сутки после начала черновика, либо через минуту после открытия уже старого черновика | Один раз на UUID; отменяется после завершения/удаления черновика; открывает план |
| Явно пропущенный/частичный день | На следующий день после закрытия в выбранное время; для старого события — не ранее чем через минуту | Один раз на уровень/день. Нет автоматического выставления пропуска; следующий день остаётся доступным |
| Плановый замер | Выбранный день недели/время | Если за соответствующий день ещё нет ручного/JSON-замера; открывает измерения |
| Недельная сводка | Воскресенье, выбранное время | Предлагает посмотреть реальные последние 7 дней; открывает прогресс |
| Итоги уровня | Через 5 секунд после обнаружения закрытого уровня/всех закрытых дней | Одна постановка на уровень; открывает отчёты; дата «через 3 месяца» не выдумывается |

Тренировочное напоминание, замер, сводка и итоги настраиваются независимо; выключение
общего тумблера отменяет все ожидающие уведомления SportFit. Для черновика и явно
пропущенного дня используется общий дополнительный тумблер. Причины пропусков
записываются отдельно, автоматически не назначаются.

## Реализация и iOS

`UNUserNotificationCenter`, локальные `UNCalendarNotificationTrigger`, **без APNs,
сервера, фонового polling и Background Modes entitlement**. Для самих локальных
уведомлений не добавляется платная capability. Это не подтверждение их доставки
после истечения конкретной бесплатной подписи.

Очередь одноразовых событий на 14 дней, максимум 48 ожидающих запросов приложения
(ниже системного предела 64). Открытие/возврат в приложение, изменение настроек,
сохранение черновика, закрытие дня, новый замер и восстановление пересобирают очередь.
Пересборки сериализованы: устаревшая операция не оставляет запросы после выключения.
Идентификаторы стабильны, сохранённые одноразовые события не переносятся бесконечно
вперёд и не дублируются каждым открытием. Тексты не содержат веса, пульса, имени
или свободных медицинских заметок. Нажатие ведёт к соответствующему разделу.

Нельзя гарантировать точную минуту доставки: действуют настройки iOS, фокусирование,
выключенный телефон и другие системные ограничения. Смена часового пояса и очереди
учитывается при следующем открытии. Без открытия дольше 14 дней новые события
не добавляются. После истечения бесплатной подписи запуск требует переподписи;
доставка уже поставленных событий в этом состоянии **не проверена на устройстве**.
При переносе/восстановлении копии настройки сохраняются, общий тумблер выключен:
пользователь включает его и даёт разрешение заново.

## Мотивация

Недельная сводка — реальные занятия/подходы/активные дни, без очков и рейтингов.
Индикатор плана — полностью закрытые занятия / все занятия снимка уровня.
Серия — последние подряд полностью закрытые тренировочные дни; дни отдыха
игнорируются, частичный день/явный пропуск начинает новую серию. Это справочная
история, без штрафа, блокировки занятий или повышения нагрузки. Дополнительный
отдых и перерыв не создают автоматических пропусков.

Автотесты проверяют планы, сроки/границы очереди и реальные объекты локальных
запросов. Разрешение и реальная доставка проверяются на iPhone отдельно; автотест
не выдаётся за подтверждение уведомления на заблокированном физическом устройстве.
