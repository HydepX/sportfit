# План SportFit из таблицы — 14.11.2026

Источник: `SportFit_12_weeks_Codex.xlsx`, SHA-256 указан в `derived_from`
новой программы. Импортируются значения трёх таблиц Exercises, Schedule,
Workout_Items. Текстовые указания из README книги не исполняются как команды.
Исходные значения этих таблиц зафиксированы отдельно в
`Tests/Fixtures/workbook_rows.json` для проверки всех 624 назначений.

## Состав

36 упражнений в новой библиотеке, 48 занятий, 36 дней отдыха, 84 дня программы.
624 строки назначений. Три упражнения библиотеки сейчас не назначены в занятиях;
они не добавляются туда автоматически. Уровень начинается по выбору пользователя,
порядок дней сохраняется без календарного срока. Даты таблицы используются как
ключи шаблона; фактические результаты датируются реальным выполнением.

Коды W01/C01/S01 и item_id сохраняются. Названия не используются как идентификаторы.
Повтор W04 в разминке и основной части — два разных назначения. Плеер получает
подходы, время и отдых по позиции и source_item_id, а не по первому совпадению W04.
Числовой rest_seconds применяется буквально; текст примечаний сохраняется отдельно.
weight_guidance остаётся текстом, фактический внешний вес вводится пользователем.

## Единицы

| Таблица | Код приложения | Запись факта |
| --- | --- | --- |
| time / сек | duration | секунды |
| time_side / сек/сторона | duration_per_side | первая и вторая стороны отдельно |
| reps / повт | repetitions | повторения |
| reps_side / повт/сторона | repetitions_per_side | повторения на каждую сторону |
| reps_total / повт всего | repetitions_total | общее количество |

20 секунд на сторону означает два последовательных отсчёта по 20 секунд.
Только после второй стороны фиксируется подход и запускается назначенный отдых.
Результат хранит seconds/otherSideSeconds; сумма времени включает обе реальные
стороны. Пустая вторая сторона не подставляется автоматически и оставляет занятие
частичным. Пауза и восстановление сохраняют текущую сторону. После фона первая
истёкшая сторона не запускает автоматически неотмеченную вторую.

## Замена прежней программы

Из поставляемых файлов убраны данные прежней программы
`fitness_12w_2026_11_09`; оба совместимых имени program_12w*.json содержат новый
`sportfit_12w_2026q4`. Старый план удаляется из выбора и архива доступных программ.
Прежние снимки назначений остаются только как часть истории, их повторный запуск
недоступен. Исторические тестовые данные перемещены в Tests/Fixtures/LegacyData
и включаются только в тестовый bundle, не в приложение.

Для чтения старых результатов каталог содержит ещё 53 прежних ID с retired=true.
Библиотека показывает только 36 новых упражнений; исторические ID нужны для
валидации старых копий и отображения записанных названий. Старые результаты SQLite,
замеры, профиль, цели и заметки не переписываются. Старый уровень получает retiredAt,
который не означает его успешное завершение.

Незавершённый старый черновик сохраняется целиком в journal.retiredDrafts: те же UUID,
записанные подходы, пауза и исходные назначения. Он виден в истории только для чтения,
не считается выполненной тренировкой и включается в копию v4. Основной активный
черновик очищается после сохранения архивной записи. Замена выполняется через
существующий redo-журнал, с предыдущими байтами файлов в before-restore.
plan_release.v1.json защищает последующие пользовательские импорты от повторной замены.
Восстановление старой копии не возвращает выведенную из обращения программу в выбор.

## Иллюстрации

Приложение использует исходные изображения коллажей и отображает выбранные ячейки,
не перерисовывает анатомию и не генерирует отсутствующие варианты. Коды первого
коллажа определяют W01–W04, C01–C03, S01–S02. Второй коллаж сопоставлен по названиям:

S03→11, S04→12, S06→7, S09→9, L01→18, L03→14, L04→13,
L05→25, L06→22, L07→16, K01→31, K03→28, K04→29,
K05→27, K06→35, K07→36, A02→38.

Всего подготовлено 26 соответствий. Для S05 (жим стоя), S07, S08, L02 (выпады с
опорой), K02, K08 (боковая планка с колен), K09 и трёх неназначенных A01/A03/A04
подходящей иллюстрации не подтверждено. Используется исходная текстовая техника,
а не картинка другого упражнения. Для L07 указание устойчивой опоры из таблицы
сохраняется рядом с техникой.

Ожидаемые исходные файлы: media/technique_coded.jpg и media/technique_numbered.jpg
(допускаются исходные JPEG/PNG-байты без перерисовки). В текущем чате изображения
доступны для визуального чтения, но исходные файлы ещё не предоставлены среде.
Проверка настоящей IPA требует этих файлов и блокирует выдачу пакета без иллюстраций.
