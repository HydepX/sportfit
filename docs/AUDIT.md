# SportFit: аудит и границы проверки

Исходная ревизия: `06220350c835454d8bb33dd83dfcd1d1f02707e4`.

В репозитории найден ранний SwiftUI MVP, 53 упражнения и программа на 84 календарных дня / 48 занятий (09.11.2026–31.01.2027). HTML-прототип, дополнительные медицинские спецификации и проверенные медиа отсутствуют. Существующий визуальный стиль сохранён. Замены wall_push → press_alt и march_seated → toe_moves взяты исключительно из исходного плана.

## Исправления

- Пять вкладок из задания; библиотека доступна из профиля.
- Пауза сохраняет предыдущую фазу и остаток отдыха; абсолютный дедлайн работает после перезапуска/блокировки. Итог фиксирует окончание времени, не продолжает считать до нажатия «сохранить».
- Запись черновика сначала на диск, затем в UI. Повреждённая история/замеры не перезаписываются новыми пустыми данными. UUID результата защищает от повторного сохранения после сбоя между записью истории и удалением черновика.
- Исправление/удаление подходов, смена порядка до начала упражнения. Защита от второй записи занятия в тот же день той же программы.
- Валидатор дат, этапов, упражнений, замен, назначений; предыдущие версии программ архивируются. Результаты содержат снимки названий, целей и подходов.
- Замеры редактируются; добавлены рост/ИМТ, грудь, бёдра, мышечная масса, фильтры периода и графики по показателю/источнику.
- Профиль и цели; переносы и пропуски занятий; календарь недели, месяца и квартала. Статистика по периоду/упражнению и отчёт программы.
- Резервная копия v2 содержит каталог, текущую программу, архив, профиль, переносы, черновик, результаты, legacy-подходы и замеры. SHA-256 обнаруживает повреждение payload; это не шифрование и не подпись подлинности. Старые экспорты v1 читаются без checksum; отсутствовавшие в v1 профиль/программы сохраняются.
- Восстановление с подтверждением, предварительным сохранением старых файлов, атомарным redo-журналом и повторным применением при старте. Личные данные никогда не передаются в GitHub.
- Локальный MP4 с циклом и JPG по стабильному ID; безопасное состояние при отсутствии файлов. Черновые непроверенные «типичные ошибки» скрыты.
- Обычная сборка не содержит HealthKit entitlement. Отдельный opt-in spec компилирует чтение Apple Health. Он не доказывает возможность бесплатной подписи.
- CI: тесты ядра, тесты симулятора, unsigned device IPA, проверка ZIP/Info.plist/библиотеки/программы, SHA-256 артефакта; дополнительная компиляция HealthKit.

## Данные, которых нет в источнике

В поставленном JSON нет назначенного количества подходов и правил прогрессии по этапам. Приложение не изобретает их: используется `prescriptions` в импортируемом плане; без него видны ориентиры повторов и отдыха из каталога и сообщение об отсутствии назначений. Согласованные новые правила должен содержать новый план. Медицинские нагрузки и ограничения не расширялись.

## Проверено и не проверено

Локальная машина Linux: исполняются Swift Package тесты ядра, Python проверки и синтаксический разбор всех Swift-файлов. Linux не предоставляет SwiftUI, HealthKit, Xcode и iOS Simulator. Синтаксический разбор не заменяет компиляцию приложения.

GitHub API при аудите заблокирован HTTP CONNECT 403; страница Actions без доступной браузерной авторизации возвращает 404. Заявленные пользователем сборки #27/#28 независимо не подтверждены. Окончательная готовность требует зелёной новой сборки Actions и проверки скачанной IPA; не объявлять проект завершённым без этого.

## Проверки на iPhone 15

- Установка/обновление через AltStore, сохранность данных и поведение после истечения подписи.
- Полная тренировка: разминка, подходы, исправление, отдых, пауза, блокировка, принудительное закрытие, продолжение, заминка, итог.
- Календарь и переносы в локальной временной зоне, частичные/пропущенные результаты.
- Замеры, клавиатура, VoiceOver, крупный текст, длинные названия, одноручное управление.
- Экспорт во «Файлы», восстановление после подтверждения, отказ от повреждённой/неподдерживаемой копии.
- Видео с собственными разрешёнными материалами, отсутствие медиа.
- HealthKit проверяется только в разрешённой подписанной конфигурации; наличие Huawei Health не гарантирует категории Apple Health.

Остаются ограничения: HealthKit сейчас показывает доступные показатели при обновлении, без фонового импорта и долговременного архива всех категорий; нет проверенного на устройстве UX и восстановления после реального исчерпания места. Квартальный отчёт привязан к programId: при редактировании версии с тем же ID результаты остаются в общем отчёте этой программы; для нового квартала нужен новый ID.
