# Бесплатная установка с Windows 11 на iPhone 15

Статус: инструкция подготовлена для проверки; установка на физическом устройстве и совместимость конкретной версии AltStore/подписи с HealthKit пока не проверены. Неподписанный IPA сам по себе не устанавливается на iPhone.

1. Открой репозиторий → Actions → последнюю **успешную** сборку `iOS tests and unsigned iPhone IPA` нужного коммита. Проверь, что оба задания (`core`, `build`) зелёные.
2. Скачай artifact `SportFit-unsigned-iphone-<полный SHA>` и распакуй ZIP. Внутри — IPA и SHA-256. Это artifact GitHub, не кнопка скачивания исходного кода.
3. В PowerShell выполни `Get-FileHash .\SportFit-unsigned.ipa -Algorithm SHA256` и сравни с `.sha256`. Для скачивания artifact GitHub обычно нужна авторизация. Не скачивай IPA из сторонних источников.
4. Скачай AltServer только с https://altstore.io/ и следуй актуальному руководству Windows: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows . Выполни указанные там требования к iTunes/iCloud и Bonjour; не используй случайные перепакованные установщики.
5. Подключи iPhone кабелем, разблокируй и подтверди доверие компьютеру. Через AltServer установи AltStore Classic на этот iPhone. Apple ID/пароль вводи только непосредственно в официальном AltServer/AltStore; не отправляй их разработчику и не сохраняй в проекте.
6. Выполни указанные iOS действия доверия профилю и включения Developer Mode, если они запрошены системой/официальным руководством. Не отключай другие механизмы безопасности.
7. Передай IPA в «Файлы» iPhone. В AltStore Classic открой My Apps → `+`, выбери IPA и дождись подписи и установки.
8. Запусти SportFit. Проверь наличие каталога из 53 упражнений и календаря 09.11.2026–31.01.2027. Проведи короткое тестовое занятие, закрой и открой приложение, проверь сохранение результата. До первой настоящей тренировки проверь экспорт и восстановление на тестовых данных.
9. Проверь срок действия подписи в AltStore и настрой регулярное Refresh при доступном AltServer. Для бесплатного Apple ID обычно действует срок 7 дней и ограничение числа активных приложений (AltStore тоже занимает место); точные ограничения сверяй с текущим официальным руководством. Не покупай подписку для выполнения этой инструкции.
10. Перед обновлением/refresh экспортируй копию. Для сохранения контейнера данных обновляй прежнее приложение с тем же Apple ID и bundle ID, не удаляя его. Если iOS/AltStore предлагает удаление, сначала обеспечь внешнюю копию. Истечение подписи блокирует запуск; не считай это гарантией сохранности данных после последующей переустановки.

## HealthKit и Huawei

Обычная IPA намеренно собирается без `com.apple.developer.healthkit`. Ручные замеры, JSON-импорт и резервные копии работают независимо от разрешений Apple Health. Дополнительный `project-healthkit.yml` включает код чтения и entitlement, но unsigned сборка и поддержка entitlement подписывающим сервисом — разные проверки. Нельзя обещать HealthKit при бесплатной подписи через AltStore до проверки профиля и запуска на устройстве. Не пытайся вручную дописать entitlement в неподходящий provisioning profile.

Для разрешённой HealthKit-конфигурации: устройства Huawei синхронизируются с Huawei Health, затем проверь разрешения передачи в Apple Health и реальные записи в каждой категории. В SportFit → Профиль → Apple Health запроси доступ. Отсутствие записей может означать отсутствие источника или запрет чтения; HealthKit не сообщает приложению, что пользователь отказал в чтении.

Официальные источники для проверки актуальных правил:

- https://developer.apple.com/support/compare-memberships/
- https://developer.apple.com/help/account/reference/supported-capabilities-ios/
- https://developer.apple.com/documentation/healthkit
- https://faq.altstore.io/altstore-classic/

12.11.2026 официальная таблица Apple прочитана: HealthKit отмечен также в колонке бесплатного Apple Developer. Это не доказывает сохранение capability конкретной версией AltServer. Для проверки подготовлена отдельная ad-hoc HealthKit trial IPA, которую AltStore должен переподписать; результат установки и чтения проверяется на iPhone. При отказе используется обычная IPA и локальный импорт XML, без покупок и обходов. Полная спецификация и приёмочный тест: [Блок 07](BLOCK07_HEALTH.md).

## Что сообщить после проверки

Номер успешной сборки, SHA коммита, версия iOS/AltStore, удалось ли открыть приложение, сохранился ли тестовый результат после перезапуска, экспортировалась/восстановилась ли копия. Пароли, коды и сами личные данные не присылай.
