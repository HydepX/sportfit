# Блок 03 — точные параметры выполнения

- `program_12w_with_sets.v2.json`: 48 отдельных тренировок на 12 недель; для каждого пункта указаны `sets`, `mode`, `target_reps` либо `target_seconds`, `rest_seconds`.
- `fitness_12_weeks_with_sets_v2.html`: старый каталог с дополнительной вкладкой «Точный план на 12 недель».
- `exercises.v1.json`: существующий каталог 53 упражнений с неизменными ID.

Параметры назначений — предложенная детализация ранее заданных диапазонов, а не клиническое предписание. Отмеченные упражнения требуют разрешения врача. Вес гантелей не задан принудительно, фиксируется при выполнении.

`target_reps` для `repetitions_per_side` — на каждую сторону. `breath_cycles` — число дыхательных циклов. `duration` — секунды. Отдых означает паузу между подходами.
