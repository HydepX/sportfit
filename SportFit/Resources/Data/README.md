# Данные блока 03

Поместите сюда два файла без переименования:

- `exercises.v1.json` — каталог 53 упражнений из `BLOCK03_iOS_library_package(1).zip`.
- `program_12w.v1.json` — 12-недельная программа из того же ZIP.

Для загрузки через сайт GitHub откройте эту папку, нажмите **Add file → Upload files** и перетащите оба распакованных файла. GitHub Actions проверит целостность ID при следующей сборке.

Изображения и MP4 пока отсутствуют — их не нужно создавать или загружать для первого запуска.
