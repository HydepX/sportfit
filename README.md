# SportFit — личный фитнес-дневник для iPhone

Нативное SwiftUI-приложение, iOS 17+. Офлайн, без регистрации, серверов и передачи личных данных в GitHub. Библиотека содержит 53 упражнения; текущая программа — 48 занятий и дни отдыха в 12 блоках по 7 дней. Уровень проходится последовательно без календарных сроков.

## Возможности рабочей ветки

- Пять вкладок: Главная, План, Тренировка, Прогресс, Профиль.
- Уровни в своём темпе: карточки дней по неделям, явное закрытие дня, отдых, частичные результаты, пропуски и архив.
- Тренировка с разминкой/заминкой, реальными повторениями/весом/секундами, отдыхом, паузой, редактированием подходов и порядком упражнений.
- Сохранение и продолжение черновика; история с защитой от повторного сохранения.
- Замеры веса, роста/ИМТ, жира, мышечной массы, талии, груди и бёдер; исправление/удаление, графики по периоду и источнику.
- Статистика реальных тренировок, фильтры упражнения/периода, отчёты программ.
- JSON-импорт новых планов, архив предыдущих версий; неизменяемые снимки результатов.
- Экспорт и восстановление копии с подтверждением, SHA-256 и журналом восстановления.
- Профиль/цели; независимый от HealthKit ручной ввод и импорт измерений.
- Локальные JPG/MP4 по постоянному ID; понятное состояние при отсутствии медиа.
- Дополнительная конфигурация чтения Apple Health; обычная IPA не требует HealthKit capability.

Реализация в ветке **не означает подтверждённую сборку и работу на устройстве**. История проверок и ограничения: [аудит](docs/AUDIT.md).

## Проверки

Без Xcode (Swift 5.9+ и Python 3):

```sh
python3 scripts/validate_data.py
swift test
python3 -m unittest discover -s Tests/Python -v
```

macOS с Xcode и XcodeGen:

```sh
brew install xcodegen
xcodegen generate --spec project.yml
python3 scripts/test_simulator.py
```

GitHub Actions запускается при push и вручную, выполняет тесты и создаёт неподписанный IPA для физического iPhone. Подробности: [установка с Windows через AltStore Classic](docs/INSTALL_WINDOWS.md).

## Данные и ограничения

[Форматы импорта, медиа, архивов и резервных копий](docs/DATA_FORMATS.md).

В новый встроенный план v2 перенесены точные назначения из пользовательского архива: 48 занятий, 984 пункта. Они отображаются отдельно от фактически выполненных подходов. Медиа пока отсутствуют. HealthKit, подпись/установка, VoiceOver и полный сценарий на iPhone требуют отдельной проверки. Не удаляй приложение без внешней резервной копии; при бесплатной подписи необходимо регулярно обновлять её через AltStore.

Это персональный дневник, не самостоятельное медицинское назначение. Щадящие замены сохранены из исходного JSON; ограничения и нагрузку необходимо сверять с согласованной программой.


## Последовательные уровни

[Правила блока 05](docs/BLOCK05_PLAN.md): запусти уровень, проходи дни по порядку,
сохраняй тренировку и закрывай день. Перерыв не создаёт пропусков. Закрытие уровня
с неполными результатами требует подтверждения. Следующий уровень подключается
отдельной программой; нагрузка автоматически не увеличивается. Старые данные сохраняются.

## Точные назначения и дневник за период

Программа `program_12w_with_sets.v2.json` используется по умолчанию. Для ранее
импортированного неизменённого исходного плана v1 предусмотрено обновление с
сохранением старой версии в архиве. Собственные изменённые программы и активные
черновики автоматически не переписываются. План v2 также можно выбрать через
импорт программы JSON в профиле.

Во время занятия измени поле фактических повторов/секунд перед отметкой подхода;
сохранённый подход можно исправить кнопкой «Исправить». Плановые значения останутся
прежними. «Прогресс» показывает последние 7 дней, кнопку раскрытия каждой тренировки,
выбор дат и более раннюю историю. Внутри — план и фактические значения каждого подхода.
