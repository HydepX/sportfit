# SportFit

Персональное iOS-приложение для 12-недельных тренировок. Разработка ведётся на Windows; нативный клиент собирается на macOS runner GitHub Actions.

Статус: старт разработки. Источник дизайна — `forma_fitness_prototype_v5(1).html`, источники тренировок — пакет `BLOCK03_iOS_library_package(1).zip` (53 упражнения и программа 12 недель). Медиа готовятся отдельно.
