# SportFit — личный фитнес-дневник для iPhone

Нативный SwiftUI-проект по согласованному HTML-макету v5 и блоку 03. Основная цель — 12-недельные индивидуальные тренировки, библиотека 53 упражнений, журнал подходов, локальные данные и последующая интеграция Apple Health.

## Первый этап реализации

- Главная с текущей программой и быстрым переходом к тренировке.
- Календарь 12 недель, понедельник/среда/пятница/воскресенье; воскресенье — восстановительная сессия.
- Библиотека по ID, поиск, группы мышц, техника, ограничения; видео пока отсутствуют и не выдаются за готовые.
- Отметки выполненных подходов сохраняются на iPhone.
- Импорт \`exercises.v1.json\` и \`program_12w.v1.json\` через стандартное приложение «Файлы»; после импорта они работают офлайн.
- Сборка для **симулятора** через GitHub Actions (без платных Apple-сертификатов).

### Важно о первой версии

Это **ранний функциональный каркас**, а не готовая медицинская/спортивная рекомендация. Полные назначения нагрузки по неделям (число подходов, RPE, паузы), условные замены по допуску врача, видео, резервные копии и HealthKit находятся в работе. Предложения по повторениям из библиотеки являются текстом первоисточника, а не окончательным назначением. Не использовать как самостоятельное основание для нагрузки.

### Импорт данных

Исходный пакет: \`BLOCK03_iOS_library_package(1).zip\`. Из-за ограничений передачи локальных вложений в GitHub данные **не добавлены в этот коммит автоматически**. Их можно извлечь из ZIP и добавить в \`SportFit/Resources/Data/\` в репозитории либо импортировать по отдельности через «Настройки» на телефоне. Пара JSON-файлов должна быть из одного пакета; проверка \`scripts/validate_data.py\` проверяет ссылочную целостность.

## Сборка

1. На macOS: \`brew install xcodegen\`, затем \`xcodegen generate\`.
2. Открыть \`SportFit.xcodeproj\` в Xcode; для локального теста настроить подпись.
3. На Windows: сборку без подписи для **iOS Simulator** проверяет workflow \`iOS simulator build\` на macOS GitHub Actions.

**Не путать:** успешная сборка для Simulator не устанавливается на физический iPhone. Бесплатная подпись для личной установки через Xcode/AltStore — отдельная задача. HealthKit entitlement добавлен в проект, но не подтверждён на реальном iPhone; прямой доступ к Apple Health пока не реализован.
