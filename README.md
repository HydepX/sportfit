# SportFit — личный фитнес-дневник для iPhone

Нативное приложение на SwiftUI по согласованному прототипу v5. Исходные данные **53 упражнений** и **12-недельной программы** загружены в `SportFit/Resources/Data/`.

## Реализовано (ранний MVP)

- Главная, календарь 12 недель, выбор дня и просмотр техники упражнений.
- Четыре занятия в неделю: Пн/Ср/Пт и восстановительная сессия Вс.
- Каталог 53 упражнений с постоянными ID, инструкциями и предупреждениями.
- Плеер тренировки: подготовка, отметка подходов (повторы/вес/секунды), таймер отдыха, добавление времени, пауза, пропуск с причиной, навигация, досрочное завершение, итоговый отчёт.
- Незавершённое занятие сохраняется локально; есть журнал завершённых тренировок.
- Для движений с условным разрешением врача применяются щадящие замены, предусмотренные исходной программой.
- Импорт новых JSON-файлов программы и каталога из приложения «Файлы».

## Запуск и проверка

1. Проверка структуры и связей: `python3 scripts/validate_data.py`.
2. Установить на Mac XcodeGen: `brew install xcodegen`.
3. Сгенерировать проект: `xcodegen generate --spec project.yml`.
4. Открыть `SportFit.xcodeproj` в Xcode или собрать для iOS Simulator с `CODE_SIGNING_ALLOWED=NO`.
5. Автоматическая сборка Simulator настроена в `.github/workflows/ios-build.yml`.

**Важно:** сборка для симулятора не является IPA для физического iPhone. Бесплатную подпись, установку и доступность HealthKit ещё требуется проверить отдельно.

## Ограничения первой версии

- Медиафайлы пока отсутствуют: в плеере и карточке техники отображаются заглушки.
- Apple Health, замеры тела, графики, резервные копии, уведомления и полная прогрессия нагрузки ещё не реализованы.
- Количество выполняемых подходов выбирается пользователем; текстовые ориентиры повторений взяты из библиотеки, а таймер отдыха на 45 секунд является временной настройкой интерфейса.
- Это ранний каркас, не самостоятельное медицинское назначение тренировки. Ограничения и разрешённую нагрузку следует сверять с лечащим врачом.
- Результаты хранятся на самом устройстве, **не загружаются в GitHub**. До удаления приложения необходимо реализовать резервное копирование.

## Структура

- `SportFit/Models.swift` — модели упражнений и плана.
- `SportFit/FitnessStore.swift` — работа с библиотекой и импортом JSON.
- `SportFit/WorkoutEngine.swift` — черновик, таймер, сохранение тренировок.
- `SportFit/WorkoutPlayer.swift` — интерактивный тренировочный плеер.
- `SportFit/WorkoutScreens.swift` — календарь и журнал.
- `SportFit/Resources/Data/` — исходная библиотека и квартальная программа.
